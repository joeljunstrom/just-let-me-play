# Changelog

## v0.5.2

- Pick your notification sound: right-click menu → Sound, or
  `/jlmp sounds <name>`. Six choices from whisper to raid warning, previewed
  on select.
- Saner default: the ready check sound from v0.5.1 was way too much. Default
  is now the whisper ping.

## v0.5.1

- Audible notification: the slot-freed sound was the standard checkbox tick,
  indistinguishable from normal UI clicks. Now the ready-check sound.

## v0.5.0

- Skin options window: right-click the widget, "Skin options...". Sliders for
  width, height, font size, corner radius and border width, a font face picker,
  and color swatches for background, border and text.
- Dungeon picker: pick dungeons from checkboxes in the right-click menu; the
  filter constrains results on both search paths.
- Widget hides when you accept an invite and join a group, returns when you
  leave.
- Shift-click leaves your oldest application.
- The count shows what the current search can reach.
- Glow only when there are results to apply to.
- Tooltips show dungeon names instead of "Unknown".
